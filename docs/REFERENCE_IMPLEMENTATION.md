# 参考站复刻与功能落地

参照 LinkFox 公开首页与用户提供的截图，复用页面结构、功能入口与操作流程，使用自有品牌、代码、数据库、接口和本地 SVG 示意封面。运行时不调用 LinkFox API，不加载其脚本或素材。

## Agent 的实际工作方式

`backend/workspace.py` 中的 `StandardPlanner` 根据模式构建可编辑的标准方案。此过程是确定性规则，不声称进行了 AI 商品识别。`JsonHttpPlanner` 通过独立的 `agent.plan` 能力调用后续配置的文本模型，只在用户点击“AI 优化方案”时调用。

当前方案各生成步骤共享用户提供的原始商品素材，独立调用生成能力；尚不支持把上一阶段生成结果自动传给下一阶段的依赖图。套图按主图、场景、细节、卖点分图生成；电商组合默认四张商品图与一段展示视频。

确认方案使用 SQLite 事务，整套创建任务与积分冻结要么全部成功，要么全部回滚。重复确认同一方案返回已有任务。方案修改使用 revision 防止覆盖已变更的方案。生成仍由通用 JobRunner 执行，保留供应商快照、原任务查询与幂等结算。

## 保留接口与当前边界

真实 AI 生成、文本规划和链接资料解析，需要对应供应商配置。未配置时生成任务等待，不冻结积分；文本规划与链接解析明确报未配置。

链接解析支持通过独立 HTTP JSON 服务导入标题与参考资料；当前不内置 Amazon 抓取器、登录或验证码处理。原始商品图片仍由用户上传或选择。解析服务调用与文本规划目前不单独扣平台积分，供应商自身可能计费，正式商业计费需要补充这两类用量账本。

灵感封面是自制排版示意，不是实际 AI 输出。图片设计是裁剪、尺寸、文字、水印的本地编辑器，尚非支持任意图层拖拽的画布。会员订阅与真实支付订单仍需连接商户网关；已保留网关契约，详见 README。
