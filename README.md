# 商景 Studio

独立开发的电商创作工作台。图片、模特、视频功能通过能力接口调用模型，业务逻辑不依赖供应商 SDK。模型接口与密钥可后续配置。

## 启动

需要 Node.js 20.19+（本机验证为 24.15）和 Python 3.11+。Windows PowerShell 在本目录执行：

```powershell
.\start.ps1
```

打开 http://127.0.0.1:8000，首页可直接浏览，点击登录 / 注册创建第一个管理员账号。源码变更后使用 `.\start.ps1 -Build`。脚本不更改系统执行策略；若环境限制脚本执行，可按下面的手动命令启动。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements-lock.txt
npm.cmd ci
npm.cmd run build
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

开发时分别运行后端和 `npm.cmd run dev`，访问 http://127.0.0.1:5173，Vite 会代理 `/api` 到本地后端。接口文档位于 http://127.0.0.1:8000/docs。

## 明确边界

AI 出图、试衣、语音和视频内容依赖后续配置的模型，没有配置时不会生成虚假作品。通用 HTTP 适配器适用于 JSON 请求 / 响应，厂商签名、multipart、多个模型组合的复杂工作流需要增加专用适配器。

图片翻译、高清放大、模特换场景等入口目前调用对应能力；效果、时长和分辨率最终取决于所配置的模型。套图功能按角色分图生成，可通过独立文本规划接口优化方案，尚未包含自动商品视觉识别。带货口播与视频翻译可绑定一体化服务；若供应商分别提供语音、数字人和翻译，需要在适配器中编排。

支付保留了 `PaymentGateway` 接口，未连接支付商户、不创建假充值。在线支付返回未配置提示；当前积分可由管理员发放。生产收费上线还需接入真实订单、签名校验、幂等支付回调、退款和对账，并完善注册验证与风控。当前无订阅套餐扣费。

本地文件与 SQLite 用于当前可运行版本；正式部署可替换为对象存储、数据库迁移和独立队列。当前调度器支持单后端进程、并发 2 个任务，不要直接启用多个 Uvicorn worker。

## 模型解耦

见 [模型接入文档](docs/MODEL_INTEGRATION.md)。核心结构：

```text
src/                        React 工作台
backend/catalog.py          业务功能目录、能力和默认价格
backend/main.py             账号、素材、任务、配置、积分 API
backend/jobs.py             通用调度、生命周期和积分结算
backend/workspace.py        商品、链接、Agent 方案与规划 / 解析适配器
backend/adapters/base.py    统一请求、结果和适配器契约
backend/adapters/http.py    通用协议转换
backend/adapters/__init__.py 适配器注册表
backend/local_image.py      无模型的本地图片处理
backend/payments.py         支付网关契约
data/                       本地数据、原文件和密钥（已忽略）
```

`data/secret.key` 是解密模型密钥所必需的文件，备份数据库时须一起保管；更换或删除会导致原密钥无法解密。真实密钥不进入前端返回、Git 或日志。

## 验证

```powershell
npm.cmd run build
.\.venv\Scripts\python.exe -m pytest -q
```

测试使用临时数据库和仅存在于测试中的适配器，覆盖实际图片输出、账号隔离、积分并发保护、重复结算、失败退回、配置恢复任务与 HTTP 映射。

`scripts/qa_seed.py` 只针对 8011 端口的独立 QA 环境生成示例账号与原创几何示例图，不用于正式运行的数据目录。
